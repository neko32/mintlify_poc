このページでは、ローカルで catcafe を起動し、デモデータに質問します。

## 必要なもの

- Python 3.12 以上
- [uv](https://docs.astral.sh/uv/)
- Docker（Docker Compose を含む）
- [LM Studio](https://lmstudio.ai/)

## セットアップ

<Steps>
  <Step title="リポジトリを取得する">
    ```bash
    git clone https://github.com/neko32/catcafe.git
    cd catcafe
    ```
  </Step>
  <Step title="依存パッケージをインストールする">
    仮想環境を作成し、`seed` と `ui` の extra をインストールします。

    <CodeGroup>
    ```powershell PowerShell
    uv venv .venv --python 3.12
    .venv\Scripts\Activate.ps1
    uv pip install -e ".[seed,ui]"
    ```

    ```bash bash
    uv venv .venv --python 3.12
    source .venv/bin/activate
    uv pip install -e ".[seed,ui]"
    ```
    </CodeGroup>
  </Step>
  <Step title="デモデータを生成する">
    ```bash
    python scripts/seed_demo_data.py
    ```

    `data/catcafe_demo.db` に SQLite のデータベースを作成します。
  </Step>
  <Step title="Fuseki を起動する">
    ```bash
    docker compose up -d fuseki
    ```

    Fuseki は `http://localhost:3030` で起動します。
  </Step>
  <Step title="データを RDF にしてロードする">
    ```bash
    python scripts/export_rdf.py --load
    ```

    `wrote ... triples` と `loaded ...` が表示されれば成功です。
  </Step>
  <Step title="LM Studio を準備する">
    LM Studio にモデルをロードし、ローカルサーバーを起動します。既定の接続先は `http://localhost:1234/v1`、既定のモデル名は `google/gemma-4-e4b` です。

    別のモデルを使うときは、次のステップの画面でモデル名を変更します。
  </Step>
  <Step title="Streamlit UI を起動する">
    ```bash
    streamlit run scripts/streamlit_app.py
    ```
  </Step>
  <Step title="質問する">
    入力欄に「猫別の予約数を多い順に教えて」と入力し、**検索** をクリックします。結果が表で表示されます。
  </Step>
</Steps>

<Tip>
  質問に失敗するときは、[トラブルシューティング](/guides/troubleshooting)を確認してください。
</Tip>

## 後片付け

```bash
docker compose down
```

Fuseki のデータは名前付きボリュームに残ります。
